## 我们的创作方向

以轻盈、灵动的方式探索 AI 影像创作，从灵感与镜头出发，逐步积累能反复使用的创作能力。

| 方向 | 探索内容 |
| --- | --- |
| 灵感与短片 | 创意构思、短片剧本、分镜与镜头表达 |
| 画面与声音 | AI 视频生成、配音、字幕与剪辑 |
| 创作 Skills | 可复用的提示词、制作步骤与创作工作流 |
